1. net user (Consulta General)

Definición no técnica: Es como pedirle a la computadora una lista de todas las "fichas" de las personas o programas que tienen permiso para entrar y usar el equipo.
Caso de uso: Ver de un vistazo rápido cuántas y cuáles cuentas existen en el sistema (para detectar cuentas sospechosas o no autorizadas).
Fórmula o sintaxis: net user
Tabla de subcomandos/parámetros: No aplica para la consulta general.
Ejemplo: net user
Escenario de práctica / Entrevista: Te piden auditar un servidor que acaba de ser atacado. Ejecutas net user para verificar si el atacante creó un usuario nuevo para mantener el acceso.
Referencia externa: Documentación oficial de Microsoft Learn (Net user command reference).

2. net user [usuario] (Consulta Específica)

Definición no técnica: Es pedir la "ficha completa" de una persona en específico: cuándo entró por última vez, cuándo vence su contraseña y qué permisos tiene.
Caso de uso: Investigar los detalles y directivas de seguridad aplicadas a una cuenta en particular.
Fórmula o sintaxis: net user [nombre_de_usuario]
Tabla de subcomandos/parámetros: No aplica.
Ejemplo: net user Juan
Escenario de práctica / Entrevista: Pregunta de entrevista: "¿Cómo verificas cuándo vence la contraseña de un usuario local desde la consola?" Respuesta: Ejecutando net user [usuario] y revisando la línea La contraseña expira.
Referencia externa: Libro Windows Command Line Administration Instant Reference (Sybex).

3. net user [usuario] [contraseña] /add (Crear Usuario)

Definición no técnica: Sirve para dar de alta a un nuevo integrante en la computadora, asignándole su nombre y su clave de entrada.
Caso de uso: Crear cuentas para empleados nuevos o usuarios temporales sin usar la interfaz gráfica.
Fórmula o sintaxis: net user [nombre_de_usuario] [contraseña] /add
Tabla de parámetros:
Parámetro
Definición
/add
Le indica al sistema que cree la cuenta con los datos proporcionados.


Ejemplo: net user Pedro ClaveSegura123! /add
Escenario de práctica: En tu trabajo de soporte técnico, necesitas automatizar la creación de 10 cuentas de usuario mediante un script (.bat) para el departamento de contabilidad.
Referencia externa: Curso de Administración de Windows Server en Pluralsight / YouTube (canal PowerShell & CMD Basics).

4. net user [usuario] /delete (Eliminar Usuario)

Definición no técnica: Borra por completo la "ficha" y el acceso de una persona en la computadora.
Caso de uso: Dar de baja la cuenta de un empleado que ya no trabaja en la empresa.
Fórmula o sintaxis: net user [nombre_de_usuario] /delete
Tabla de parámetros:
Parámetro
Definición
/delete
Remueve la cuenta de usuario del sistema de forma permanente.


Ejemplo: net user Pedro /delete
Escenario de práctica: Un empleado es despedido de forma inmediata por incumplimiento de políticas de seguridad. Tu jefe te pide revocar su acceso local en menos de 2 minutos.
Referencia externa: Documentación de Respuesta a Incidentes de NIST (Guías de desaprovisionamiento).
5. net user [usuario] /times:[horario] (Restricción de Horario)


Definición no técnica: Establece los días y las horas exactas en las que se le permite a una persona iniciar sesión. Fuera de ese horario, la puerta está cerrada.
Caso de uso: Evitar que empleados del turno matutino accedan a los equipos durante la madrugada o fines de semana.
Fórmula o sintaxis: net user [nombre_de_usuario] /times:{día[-día],hora[-hora] | all}
Tabla de formatos de tiempo:
Formato
Definición
M-F,08:00-17:00
De Lunes a Viernes (Monday-Friday), de 8 AM a 5 PM.
all
Permite el acceso a cualquier hora del día.


Ejemplo: net user Maria /times:M-F,08:00-17:00
Escenario de práctica / Entrevista: "¿Cómo evitas que los practicantes se conecten a los sistemas del banco durante los fines de semana?" Respuesta: Configurando el parámetro /times en su cuenta de usuario.
Referencia externa: Libro CompTIA Security+ Sybex Study Guide (Sección de Controles de Acceso).
6. net user [usuario] /active:{yes | no} (Habilitar / Deshabilitar Cuenta)


Definición no técnica: Pone el acceso de una persona "en pausa" (sin borrar sus archivos) o lo vuelve a activar cuando regresa.
Caso de uso: Congelar la cuenta de un empleado que sale de vacaciones prolongadas o incapacidad médica, o activar la cuenta de un usuario recién contratado.
Fórmula o sintaxis: net user [nombre_de_usuario] /active:{yes | no}
Tabla de opciones:
Opción
Definición
/active:yes
Activa la cuenta para que pueda ser utilizada.
/active:no
Desactiva e inhabilita la cuenta sin borrar su información.


Ejemplo: net user Carlos /active:no
Escenario de práctica: Un usuario reporta sospecha de phishing en su cuenta. Como medida preventiva inmediata mientras investigas, bloqueas su cuenta con /active:no.
Referencia externa: YouTube (Canal NetworkChuck - Tutoriales de Administración de Windows).

7. net user [usuario] /fullname:"[Nombre Real]" (Nombre Completo)

Definición no técnica: Le agrega la etiqueta con el nombre y apellido real a la cuenta (que a veces solo usa un apodo o ID corto).
Caso de uso: Documentar correctamente quién es el dueño real de la cuenta usr_adm01.
Fórmula o sintaxis: net user [nombre_de_usuario] /fullname:"[Nombre y Apellido]"
Tabla de parámetros:
Parámetro
Definición
/fullname:""
Define el nombre completo que se mostrará en las pantallas de inicio de sesión.


Ejemplo: net user jperez /fullname:"Juan Perez Gomez"
Escenario de práctica: En una auditoría de TI se exige que todas las cuentas genéricas o abreviadas estén asociadas con el nombre completo del empleado responsable.
Referencia externa: Manuales de acreditación ISO 27001 (Control de Identidades).

8. net user [usuario] /comment:"[Texto]" (Añadir Comentario)

Definición no técnica: Permite escribir una "nota adhesiva" en la ficha del usuario para saber quién es o para qué sirve esa cuenta.
Caso de uso: Especificar el departamento o el motivo por el cual se creó una cuenta temporal.
Fórmula o sintaxis: net user [nombre_de_usuario] /comment:"[Texto descriptivo]"
Tabla de parámetros:
Parámetro
Definición
/comment:""
Agrega un texto descriptivo de hasta 48 caracteres a la cuenta.


Ejemplo: net user ext_consultor /comment:"Consultor externo de auditoria hasta junio"
Escenario de práctica: Trabajas en el equipo Blue Team y revisar cuentas creadas por administradores anteriores. Utilizas las notas para clasificar cuáles cuentas son de servicios y cuáles de personas.
Referencia externa: Windows System Administration Command Line Handbook.


9. net user [usuario] /passwordchg:{yes | no} (Permiso de Cambio de Contraseña)

Definición no técnica: Decide si el dueño de la cuenta tiene permitido cambiar su propia clave o si únicamente el administrador puede hacerlo.
Caso de uso: Evitar que usuarios en cuentas genéricas o de recepción cambien la clave y dejen sin acceso a sus compañeros.
Fórmula o sintaxis: net user [nombre_de_usuario] /passwordchg:{yes | no}
Tabla de opciones:
Opción
Definición
/passwordchg:yes
El usuario puede cambiar su contraseña cuando lo desee.
/passwordchg:no
El usuario no tiene permitido cambiar su contraseña.


Ejemplo: net user Recepcion /passwordchg:no
Escenario de práctica / Entrevista: "¿Cómo aseguras un equipo de acceso público (Kiosko) para que los usuarios no alteren las credenciales?" Respuesta: Inhabilitando la opción de cambio de contraseña mediante /passwordchg:no.
Referencia externa: Guías de hardening para Windows de CIS Security (Center for Internet Security).

10. net user [usuario] /expires:[fecha | never] (Fecha de Expiración de Cuenta)

Definición no técnica: Le pone una "fecha de caducidad" a la cuenta. Llegado ese día, la cuenta se autodeshabilita.
Caso de uso: Configurar accesos para becarios, contratistas o proveedores temporales.
Fórmula o sintaxis: net user [nombre_de_usuario] /expires:{MM/DD/AAAA | DD/MM/AAAA | never} (El formato depende de la configuración regional).
Tabla de opciones:
Opción
Definición
MM/DD/AAAA
Inhabilita la cuenta automáticamente en la fecha indicada a las 00:00.
never
La cuenta nunca expira por fecha.


Ejemplo: net user Pasantia2026 /expires:12/31/2026
Escenario de práctica: Creas una cuenta para un auditor externo que estará en la oficina por 2 semanas. Para evitar que la cuenta quede olvidada e activa indefinidamente, le aplicas un vencimiento automático.
Referencia externa: Microsoft Learn (Managing User Accounts with Command Line).

11. net user [usuario] * (Cambiar Contraseña de Forma Oculta)

Definición no técnica: Cambia la clave de una cuenta sin que los caracteres se vean en pantalla mientras escribes, evitando que personas a tu alrededor la descubran.
Caso de uso: Restablecer la contraseña de un usuario o administrador de forma segura frente al cliente o en entornos compartidos.
Fórmula o sintaxis: net user [nombre_de_usuario] *
Tabla de parámetros:
Parámetro
Definición
*
Solicita la nueva contraseña y la confirmación en modo oculto (sin eco en pantalla).


Ejemplo: net user Admin Local *
Escenario de práctica / Entrevista: Pregunta de examen técnico: "¿Por qué nunca debes ejecutar net user Juan Clave123 directamente en producción?" Respuesta: Porque la clave queda grabada en texto plano en el historial de comandos (doskey /history). La forma segura es usar net user Juan *.
Referencia externa: Cursos de certificación Certified Ethical Hacker (CEH) - Sección de seguridad operacional (OpSec).



12. net user <usuario> /passwordchg:no

1. Definición en lenguaje no técnico:
Es una orden que le quita el permiso a un usuario para que no pueda cambiar su propia contraseña. La clave solo la podrá modificar el administrador del sistema.
2. Caso de uso:
Se utiliza en entornos corporativos o colegios cuando asignas una cuenta con una contraseña estándar a un empleado temporal, estudiante o usuario de soporte, y necesitas evitar que la cambien y luego la olviden.
3. Fórmula o sintaxis:
net user <nombre_de_usuario> /passwordchg:{yes|no}
4. Tabla con parámetros opcionales del contexto:
Parámetro
Definición / Función
yes
Permite que el usuario vuelva a cambiar su contraseña normalmente.
no
Bloquea la capacidad del usuario para cambiar su contraseña.

5. Ejemplos:
Impedir cambio de clave a un usuario llamado Invitado:
net user Invitado /passwordchg:no
Volver a permitir el cambio de clave:
net user Invitado /passwordchg:yes
6. Escenario de práctica de entrevista / Situación laboral:
Pregunta de entrevista: "Si un usuario de la empresa cambia constantemente su clave por una no autorizada y olvida el acceso, ¿cómo evitas esto mediante la consola de Windows?"
Respuesta práctica: "Ejecuto net user <usuario> /passwordchg:no desde un CMD con privilegios elevados. Esto asegura que el usuario no modifique la credencial asignada por la política del departamento de TI."
7. Referencias externas sugeridas:
Documentación oficial: Microsoft Learn (artículo sobre el comando net user).
Libros: Windows Server Administration Fundamentals (Microsoft Official Academic Course).
YouTube: Buscar "Cómo bloquear el cambio de contraseña a un usuario en CMD".

13. net user <usuario> /expires:<fecha>

1. Definición en lenguaje no técnico:
Es un temporizador para las cuentas de usuario. Permite ponerle una "fecha de caducidad" a la cuenta para que deje de funcionar automáticamente en un día determinado.
2. Caso de uso:
Gestión de accesos para pasantes, contratistas o consultores externos que solo trabajarán en la empresa durante un período fijo (por ejemplo, 30 días). Evita que la cuenta quede activa indefinidamente tras su partida.
3. Fórmula o sintaxis:
net user <nombre_de_usuario> /expires:{fecha | never}
4. Tabla con opciones y formatos:
Opción / Subcomando
Definición
mm/dd/aa
Establece la fecha límite en formato Mes/Día/Año (ejemplo: 12/31/26).
dd/mm/aa
Formato alternativo dependiendo de la configuración regional del sistema.
never
Elimina la fecha de expiración; la cuenta nunca caducará por tiempo.

5. Ejemplos:
Definir que la cuenta del contratista JuanPerez caduque el 31 de diciembre de 2026:
net user JuanPerez /expires:12/31/26
Hacer que la cuenta vuelva a no caducar nunca:
net user JuanPerez /expires:never
6. Escenario de práctica de entrevista / Situación laboral:
Pregunta de entrevista: "¿Cómo garantiza desde el área de Ciberseguridad el principio de menor privilegio con los consultores externos que se van el mes que viene?"
Respuesta práctica: "Al crear su cuenta de usuario local o de dominio, configuro la fecha límite con net user <usuario> /expires:<fecha>. De este modo, si la administración olvida deshabilitar la cuenta manualmente, el sistema bloquea el acceso de forma automatizada al vencer la fecha."
7. Referencias externas sugeridas:
Documentación oficial: Microsoft TechNet / Windows Commands Index.
Libros: CompTIA Security+ Study Guide (capítulo sobre gestión de identidades y ciclo de vida de cuentas).
YouTube: Buscar "Configurar expiración de usuarios en Windows mediante línea de comandos".

14. net user <usuario> *

1. Definición en lenguaje no técnico:
Es la forma más segura de cambiar la contraseña de un usuario desde la consola, ya que te pide escribir la nueva clave "a ciegas" (sin mostrar los caracteres en pantalla) para que nadie a tu alrededor la vea.
2. Caso de uso:
Soporte técnico y respuesta a incidentes. Cuando un administrador debe restablecer la contraseña de un usuario que fue comprometido o que la olvidó, sin dejar la nueva clave guardada en el historial de comandos en texto plano.
3. Fórmula o sintaxis:
net user <nombre_de_usuario> *
4. Tabla de comportamientos durante la ejecución:
Entrada requerida
Comportamiento en pantalla
Escriba una contraseña para el usuario:
Los caracteres no se muestran al escribir (protección visual).
Vuelva a escribir la contraseña para confirmar:
Debe coincidir exactamente con la primera para aplicar el cambio.

5. Ejemplos:
Iniciar el proceso seguro para cambiar la clave del usuario Carlos:
net user Carlos *
(El sistema responderá solicitando la clave dos veces sin mostrar los caracteres).
6. Escenario de práctica de entrevista / Situación laboral:
Pregunta de entrevista: "Si ejecutas net user Carlos 123456 estás cambiando la clave, pero ¿por qué esto es una mala práctica de seguridad y cómo lo corregirías?"
Respuesta práctica: "Es inseguro porque la contraseña queda grabada en texto claro en el historial del terminal (doskey /history) y en los logs. La forma correcta es usar net user Carlos *, lo cual solicita la contraseña con un prompt oculto."
7. Referencias externas sugeridas:
Documentación oficial: Microsoft Learn (Sección Security Guidelines for Command Line).
Libros: Windows Command Line Administration Instant Reference (Sybex).
YouTube: Buscar "Cambiar contraseña de usuario en Windows CMD de forma oculta".
