comando ipconfig:

es una herramienta de línea de comandos utilizada en sistemas operativos Windows para mostrar, administrar y diagnosticar 
la configuración de red de un equipo. Su nombre proviene de "Internet Protocol Configuration" (Configuración del Protocolo de Internet).
Al ejecutarla, te permite ver de forma rápida los datos de conectividad de tus adaptadores de red, como el Wi-Fi o el cable Ethernet.

¿Qué información básica muestra?
Cuando ejecutas el comando ipconfig por sí solo en la consola , obtienes tres datos esenciales para cada adaptador activo: 
Dirección IPv4 / IPv6: La identidad única de tu computadora dentro de la red local.
Máscara de subred: El código que delimita el tamaño y el alcance de tu red local.
Puerta de enlace predeterminada: La dirección IP del router, que es el puente para que tu equipo salga a Internet.


comando ping:

El comando ping sirve para comprobar la conexión entre tu dispositivo y otro equipo en la red (como una computadora o una página web).Funciona enviando pequeños paquetes de datos de prue[Verificar si hay internet: Te ayuda a saber si el problema de conexión es de tu red local o de un sitio web específico.
Medir la velocidad (Latencia): Mide en milisegundos cuánto tarda en ir y volver la información. Esto es lo que los jugadores de videojuegos conocen como "el ping" o "lag".
Detectar pérdida de datos: Te muestra si algunos paquetes se pierden en el camino, lo que indica una conexión inestable.
Cuando ejecutas el comando ping, la pantalla te muestra una serie de líneas con los resultados del viaje que hicieron tus datos.
Esto es lo que ves detalladamente en los resultados:
1. El intercambio de datos (Líneas principales)
Por cada paquete enviado, verás una línea con la siguiente información:
1. El intercambio de datos (Líneas principales)
Por cada paquete enviado, verás una línea con la siguiente información:
Respuesta desde... (Reply from...): Confirma la dirección IP del equipo o servidor que respondió.
Bytes: El tamaño del paquete de prueba enviado (normalmente 32 bytes).
Tiempo (Time): Cuánto tardó el viaje de ida y vuelta en milisegundos (ms). Mientras más bajo sea este número, más rápida es tu conexión.
TTL (Time to Live): Un valor técnico que indica cuántos "saltos" (routers) pueden pasar los datos antes de ser descartados.
2. El resumen final (Estadísticas)
Al terminar el proceso, el comando te muestra un reporte con:
Paquetes enviados, recibidos y perdidos: Si el número de paquetes perdidos es mayor a 0, significa que tu conexión está fallando o es inestable.
Tiempos mínimos, máximos y promedio: Te da una idea clara de la estabilidad de la velocidad de tu red.


El comando tracert (abreviatura de traceroute) 

Es una herramienta de diagnóstico de red utilizada para rastrear la ruta exacta que siguen los paquetes de datos desde tu dispositivo hasta un destino específico, como una página web o un servidor. Te ayuda a identificar en qué punto de la red ocurre una falla de conexión o un retraso de velocidad. 

El comando tracert muestra una lista detallada de todos los routers (saltos) por los que pasa tu información desde tu computadora hasta llegar a la dirección web o IP que indicaste.
Cada fila del resultado contiene 4 datos clave:
Número de salto: El orden cronológico de los routers (1 es tu módem, 2 el de tu proveedor de internet, etc.).
Tiempos de ida y vuelta (Latencia): Muestra tres columnas de tiempo en milisegundos (ms). Indica qué tan rápido respondió ese router a tres intentos distintos. Tiempos bajos son buenos; tiempos altos significan retrasos.
Nombre del host: El nombre del servidor o router (si está disponible públicamente).
Dirección IP: La identidad numérica de ese router específico.

El comando netstat (Network Statistics):
 es una herramienta de línea de comandos utilizada para monitorear conexiones de red, ver estadísticas de protocolos y diagnosticar problemas de conectividad en sistemas operativos como Windows, Linux y macOS 
Principales casos de uso
Identificar puertos abiertos y servicios en escucha.
Detectar conexiones no autorizadas o posibles aplicaciones maliciosas enviando datos.
Verificar el estado de las interfaces de red actuales y tablas de
El comando netstat muestra principalmente una lista detallada de todas las comunicaciones de red activas de tu computadora hacia el exterior, y viceversa.
Cada línea del resultado se divide en las siguientes columnas principales:
Los 5 datos clave que muestra
Proto (Protocolo): Indica el protocolo de transporte utilizado, generalmente TCP (conexión segura de ida y vuelta) o UDP (envío rápido de datos).
Dirección local (Local Address): Es la dirección IP de tu computadora seguida del número de puerto interno que se está utilizando para esa conexión (por ejemplo, 192.168.1.15:49152). Si dice 0.0.0.0 o ::, significa que está escuchando en todas las interfaces disponibles.
Dirección remota (Foreign Address): Es la dirección IP externa o servidor de internet al que tu equipo está conectado, junto con su puerto (por ejemplo, la IP de un servidor de Google, Netflix, o una página web).
Estado (State): Indica la situación actual de la conexión. Los estados más comunes son:
LISTENING: El puerto está abierto, esperando a que alguien se conecte a él (común en servidores o servicios del sistema).
ESTABLISHED: La conexión está activa y tu equipo está intercambiando datos en ese preciso momento con el servidor remoto.
CLOSE_WAIT / TIME_WAIT: La conexión se está cerrando o está esperando a terminar de limpiarse. [1]
PID (Identificador de Proceso): (Se activa usando parámetros como -o en Windows o -p en Linux). Es un número único que te dice qué programa exacto de tu sistema originó esa conexión (por ejemplo, el navegador web, Spotify, o un proceso del sistema operativo).


nslookup:
 Es una herramienta de línea de comandos utilizada para consultar servidores DNS y obtener información sobre la asignación de nombres de dominio o direcciones IP. Su nombre proviene de Name Server Lookup (Búsqueda de Servidor de Nombres).
Sirve principalmente para resolver funciones clave de red:
Traducir nombres a IPs: Descubre la dirección IP exacta detrás de un dominio (por ejemplo, qué IP tiene google.com).
Búsqueda inversa: Encuentra el nombre de dominio asociado a una dirección IP específica.
Diagnosticar problemas: Permite verificar si tu servidor DNS funciona bien o si un sitio web no carga debido a un fallo en la resolución de nombres.
Consultar registros específicos: Puede buscar datos avanzados de un dominio, como sus servidores de correo (registros MX) o sus alias (registros CNAME).

El comando arp:

Es una herramienta de consola utilizada en sistemas operativos como Windows, Linux y macOS para mostrar y modificar la tabla de caché ARP (Protocolo de Resolución de Direcciones). Su función principal es mapear direcciones IP (lógicas) con sus respectivas direcciones MAC (físicas) dentro de una red local.  

Principales parámetros del comando arp
Parámetro
Propósito
Ejemplo de uso
-a o -g
Muestra la tabla caché ARP actual con todas sus entradas.
arp -a
-d
Elimina una entrada específica o limpia la caché completa.
arp -d 192.168.1.1
-s
Agrega una entrada estática permanente (vínculo IP-MAC manual).
arp -s 192.168.1.50 00-aa-00-62-c6-09
-v
Muestra los datos en modo detallado (no disponible en todos los sistemas).
arp -a -v


📋 Ejemplos prácticos y diagnóstico
Ver los dispositivos conectados: Al ejecutar arp -a en tu terminal, verás un listado dividido en tres columnas:
Dirección de Internet (IP): El identificador lógico del equipo.
Dirección física (MAC): El identificador único de la tarjeta de red de ese equipo.
Tipo: Indica si la dirección se descubrió automáticamente (dinámica) o si se ingresó a mano (estática).

Solución de problemas de red: Si un equipo cambió de tarjeta de red o hay un conflicto de IPs, la caché puede quedar desactualizada. Ejecutar arp -d * (en Windows, con permisos de administrador) forzará al sistema a buscar de nuevo las direcciones físicas de la red. 


El comando route:
es una herramienta fundamental de red que te permite administrar las tablas de enrutamiento IP del sistema operativo. Su función principal es indicarle a tu computadora qué camino (interfaz de red o puerta de enlace) debe tomar un paquete de datos para llegar a un destino específico. 
En Windows (Símbolo del sistema / CMD)
Nota: Debes abrir el CMD como Administrador para ejecutar estos comandos.
Ver la tabla de enrutamiento:
route print


Añadir una ruta temporal:
route add [IP_Destino] mask [Máscara] [Puerta_Enlace]


Ejemplo: route add 10.0.0.0 mask 255.0.0.0 192.168.1.1
Añadir una ruta permanente (no se borra al reiniciar):
route -p add 10.0.0.0 mask 255.0.0.0 192.168.1.1


Borrar una ruta:
route delete [IP_Destino]

🐧 En Linux (Terminal)
Nota: En versiones modernas de Linux se prefiere el comando ip route, pero el comando clásico route sigue vigente en muchos sistemas. Ver la tabla de enrutamiento:
route -n


(Equivalente moderno: ip route show)
Añadir una puerta de enlace predeterminada:
sudo route add default gw [IP_Puerta_Enlace]


(Equivalente moderno: sudo ip route add default via [IP_Puerta_Enlace])
Añadir una ruta a una red específica:
sudo route add -net [IP_Destino] netmask [Máscara] gw [IP_Puerta_Enlace]
Borrar una ruta:
sudo route del -net [IP_Destino


El comando pathping : 

Es una herramienta de diagnóstico de red en la línea de comandos de Windows. Combina la funcionalidad de ping y tracert para identificar de forma precisa la pérdida de paquetes y la latencia en cada salto de una ruta de red.   
A diferencia de tracert, que solo te muestra los saltos, pathping envía múltiples paquetes a cada enrutador durante un periodo de tiempo (por defecto unos 4-5 minutos) y calcula estadísticas detalladas.
Sintaxis Básica
Para usarlo, abre el Símbolo del sistema (cmd) y ejecuta: pathping <destino>

Ejemplo: pathping www.google.com o pathping 8.8.8.8

salto: El número de parada en la ruta (0 es tu PC, 1 tu módem, etc.).
RTT (Round Trip Time): El tiempo promedio en milisegundos que tarda el paquete en ir y volver a ese punto.
Este nodo (Perdido/Enviado): Muestra si ese router específico está sobrecargado y descarta tus paquetes.
El enlace (Línea con el símbolo |): Muestra si los paquetes se están perdiendo en el cable o conexión entre un router y el siguiente.
